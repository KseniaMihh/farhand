# Glossary

One meaning per word, used identically in the documents, the database and the
code. If a word is not in this list, it is not a Farhand concept.

| Term | Meaning |
|---|---|
| **Requester** | A user who wants a product bought abroad. Not a database role — it is a position in a specific deal. |
| **Helper** | A user who buys the product locally and posts it. Also a position, not a role. |
| **Need** | A public listing: "I want product X from country B, delivered to country A." Belongs to one requester. |
| **Help** | A public listing: "I live in country B and can buy and post things from here." Belongs to one helper. |
| **Proposal** | The handshake. Connects one need with one helper. Either side can start it. |
| **Conversation** | The message thread attached to a proposal, so both sides can ask questions before agreeing. |
| **Deal** | A proposal that was accepted. Carries the money amounts, the tracking number and the status. |
| **Deal event** | One recorded status change on a deal: who changed it, from what, to what, when. Never edited or deleted. |
| **Quote** | The confirmed product price plus estimated postage, agreed before any money moves. |
| **Thank-you amount** | Optional money the requester offers for the helper's effort. Never required. |
| **Review** | A rating and comment written after a completed deal. One per side per deal. |
| **Report** | A complaint filed by a user about a user, need, help or message. |
| **Admin action** | A recorded moderator decision about an account: warn, suspend, ban, reactivate, remove content. |
| **Moderator** | Can act on reports and content. Cannot change system settings. |
| **Admin** | Everything a moderator can do, plus account-level administration. |

## Words we deliberately avoid

| Avoid | Why | Use instead |
|---|---|---|
| Order, buyer, seller | Implies Farhand is a shop | Need, requester, helper |
| Shipping service, courier | Implies Farhand carries goods | Helper posts the parcel |
| Escrow, payment | Untrue in version 1 | The requester pays the helper directly |
| Fee, commission | Farhand charges nothing | Thank-you amount |
